
# Isotonic and Spline Modeling Functions

This folder contains the supporting R functions used by the primary **Decision Limits** analysis.
These functions are sourced by the main `decision_limits.R` script and are not intended to be run independently.

## Functions
The code in this folder supports:

- restricted cubic spline modeling for binary and continuous outcomes;
- isotonic regression for binary and continuous outcomes;
- estimation of hemoglobin decision limits;
- generation of spline and isotonic regression plots; and
- standardized storage and export of model results.

For details on running the analysis and interpreting the outputs, see the `README.md` in the parent `Decision-Limits` directory.
